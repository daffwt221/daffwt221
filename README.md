### Projects

**[Homelab](https://github.com/daffwt221/homelab-raspberry-network-stack)**  
Self-hosted infrastructure running on a Raspberry Pi, with Docker, Ansible, Tailscale, Caddy, Prometheus, Grafana, DNS and private networking.

**[PitchShifter](https://github.com/daffwt221/pitchshifter)**  
Firefox extension for independent pitch and playback-speed control, built around the Web Audio API and AudioWorklets.

**[PCSpeedAPP](https://github.com/daffwt221/PCSpeedAPP-showcase)**  
Showcase of my 2023 PAP: a web application for managing computer-repair workflows, customers and repair orders.

**PRUMO**  
A private personal-finance application currently in development.
